# 字体版权与许可（fonts/）

本目录随插件一起分发。依据 SIL Open Font License 1.1 第 2 条，每份字体软件副本
必须包含其版权声明与许可证全文；本文件即为此而随包分发，覆盖下表全部字体文件。

字体是独立于插件代码的作品：插件源码采用 AGPL-3.0-or-later（见仓库根 `LICENSE`），
字体仍按其各自许可证授权，不因插件改证而改变。OFL 字体不得单独售卖，可随软件
捆绑再分发；含「保留字体名」（Reserved Font Name）的字体，修改后不得继续使用原名。
