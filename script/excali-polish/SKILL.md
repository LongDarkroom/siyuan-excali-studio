# Excali 白板打磨

你只做三件事：**找出哪里缺**、**在真源上修**、**用真字形验收**。
不要手改 SVG 里的 payload，也不要在没看过渲染图的情况下宣布「修好了」。

```bash
SKILL="<本文件所在目录>"                        # 插件里是 <插件目录>/script/excali-polish
WS="<思源工作空间根目录>"                        # 含 data/ 的目录
BOARD="$WS/data/assets/excali/<标题>.svg"
QA="${TMPDIR:-/tmp}/excali-qa"
```

前置：Node 22+、本机 Chrome/Chromium。集市安装版没有 Node 环境时，跳过脚本，改用
`excali_file_read_board` 回读元素，再按下面第 4 步清单人工核对。

## 0. 先让用户关掉这块板

编辑器**打开时会自己重写一次文件**（归一化），还可能多出误触元素、重排数组；
在它开着的时候改盘，会被内存里的旧场景覆盖。开工前确认页签已关，
并把现有文件复制一份到临时目录作为回滚点（**不要**往白板目录里放备份）。

## 1. 体检

```bash
node "$SKILL/scripts/audit.mjs" "$BOARD" --json "$QA/audit.json"
```

只看三行就够判断要不要继续：

- `BLOCKER`：必须修（开口折线上了填充、id 重复、frameId 孤儿、演示 order 重复）
- `WARN`：大概率是「看着有缺」的原因（被画框裁切、画框名压字、文字溢出、字体单一）
- `INFO`：换字体可能缺字、非画框元素带步骤号、编辑器重排痕迹

有 blocker 时退出码为 1，可以直接当门禁用。`--dump scene.json` 可导出解码后的场景，
用来和生成器逐元素对照。

## 2. 找真源，别改产物

按优先级：

1. **有生成器**（如 `make-*-board.mjs`）：改生成器 → 重跑 → 覆盖白板。绝大多数打磨都走这条。
2. **有计划 JSON**：改计划，用插件目录下的 `scripts/excali-board.mjs append/create` 重出
   （CLI 只在源码/本地安装版有；集市版没有命令行，走第 3 条）。
3. **都没有**：把 `audit --dump` 的 scene 当证据，产出「哪几个元素、改成什么」的清单，
   在编辑器里改，或先补一个最小生成器再重画。
4. **绝对不要**直接改 SVG 里 base64 的 scene：缩略图、导出、同语义去重都会对不上。

## 3. 修什么（按体检码）

| 体检码 | 画面症状 | 修法 |
| --- | --- | --- |
| `fill-open-line` | 书页/色块只有描边，像没画完 | 把折线首尾闭合（末点补回首点）再设 `backgroundColor`；Excalidraw 只填首尾相距 ≤8px 的折线 |
| `clipped-by-frame` | 边缘元素被切掉一半 | 把子元素挪进画框，或把画框放大到包住它 |
| `label-collision` | 画框名压在标题/图上 | 画框名画在框上方 20.5px；给这条带留空，或把画框整体下移 |
| `text-overflow` | 文字压出胶囊/卡片 | 换字体后必须按**该字体**重新测量宽度；中文整宽、拉丁按字体系数 |
| `font-monotony` | 整板一种笔迹，像模板 | 至少分四层：标题/正文/英文小字/编号，见下表 |
| `cjk-in-latin-font` | 中文忽大忽小、基线乱 | 含中文的句子用中文友好字体（101/102），别塞进 Comic Shanns / Cascadia |
| `glyph-arrow` | `↑ ↗ ⤢` 变方框/粗细不一 | 箭头用两笔折线画；`↗` 在霞鹜文楷里可用，但跨字体不保证 |
| `step-outside-frame` | 演示时页眉忽隐忽现 | 画框外的全局页眉不要编步骤号；步骤只编给画框成员 |
| `duplicate-id` / `orphan-frame` | 打开丢元素、画框归属乱 | 重新生成，别手工补 id |

字体角色（插件自带，数字是 `fontFamily`）：

| 角色 | id | 字体 |
| --- | --- | --- |
| 标题 / 手绘大字 | 5 | Excalifont（中文回落 Xiaolai） |
| 正文 / 说明 | 101 | LXGW WenKai Lite |
| 英文 kicker / 页脚 / 等宽小字 | 8 | Comic Shanns |
| 编号 / 数字 | 6 | Nunito |
| 强调展示字 | 102 | Smiley Sans |

一次打磨里字体≥3 种就有层次；只在**正文与标题**这两种大面积文字上拉开差异最有效。

## 4. 真字形验收

```bash
node "$SKILL/scripts/render.mjs" "$BOARD" --out "$QA"
# 看 $QA/board.png（全景）+ $QA/frame-01.png …（逐页）
```

插件自带预览看不出 roughness、填充和角度；这个渲染器补了闭合填充、角度、画框名，
字体直接从 `engine.js`/`fonts/` 按 unicode-range 加载（Excalifont + Xiaolai 就是画布真字形）。
排线填充、图片、自由笔会有近似，输出里会明说。

逐条过清单，任何一条不过就回第 2 步改源（最多 3 轮）：

- [ ] 需要填色的图形都实心（体检 `fill-open-line` = 0）
- [ ] 没有元素被画框裁切（`clipped-by-frame` = 0）
- [ ] 画框名上方 20px 带内没有字/图（`label-collision` = 0）
- [ ] 文字没有压出盒子（`text-overflow` = 0）
- [ ] 标题、正文、英文小字、编号至少三种笔迹可辨
- [ ] 中文没落在纯拉丁字体里，行高与字号协调
- [ ] 箭头落在框边、不戳进字里；线不穿文字
- [ ] 高亮/下划线的宽度跟文字实际宽度一致
- [ ] 缩略图能看出阅读顺序（起点左上，重点有且只有一处抢眼）
- [ ] 五页（或多页）逐页看过，不只看了全景
- [ ] 演示的 order 无重复、步骤连续（有演示才查）
- [ ] 结构干净：空画框 0、孤儿元素 0

## 5. 交付

报告里写清：改了什么根因、体检前后 blocker/warn 数、白板路径、QA 图路径。
提醒用户：**先关掉旧页签再重新打开**，不要在旧页签上点保存。

## 常见失败

| 现象 | 原因 |
| --- | --- |
| 截图里中文是方框/英文变衬线 | `engine.js` 没构建或路径不对；`render.mjs` 会打印“字体分片 N 条”与缺失提示 |
| 渲染图里箭头颜色不对 | 用了 `context-stroke` 的浏览器兼容问题；本渲染器按描边色生成独立 marker |
| 体检报 `label-collision` 但看着没事 | 整板底板/外边框包住标签属正常，已排除；仍报说明真有文字/图形压进 20px 带 |
| 改完重开还是旧样子 | 板子开着被旧场景覆盖；先关页签，或确认写的是同一个 `data/assets/excali/*.svg` |
| 编辑器保存后元素顺序变了 | 打开即归一化会重排，`frame-order` 只作 info；归属看 `frameId`，不靠数组位置 |

细节与实测证据见 `references/pitfalls.md`。
