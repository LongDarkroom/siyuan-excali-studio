# 两套风格的配色语义

颜色不是装饰，是**给读者的路标**。同一张图里，一个颜色只有一个意思。

## manga-ink（漫画墨线）

底 `#f7f3ea`（宣纸）· 墨 `#151515` · 卡面 `#fffdf6` · 次要 `#6d6962`

| 语义 | 色值 | 用在哪 |
| --- | --- | --- |
| 概念 | `#7fa7d8` | 输入侧的名词框，一张图最多 2 个 |
| 机制 / 流程 | `#78a67f` | 中间的处理步骤 |
| 重点 / 角色 | `#f2c14e` | **唯一的高潮**，椭圆结果节点优先给它 |
| 正文 | `#fffdf6` | 默认，不写 group 就是这个 |

规则：默认全部留白，只让 1–2 个节点带色。琥珀黄出现第三次，读者就找不到重点了。
`概念 / 机制` 两色是**可选的分区色**，只在「想强调这是两类东西」时用，且别和外框同名（见 SKILL.md 守则 4）。

## doodle-marker（涂鸦马克笔）

底 `#fbfdff`（冷白）· 墨 `#1e1e1e` · 卡面 `#ffffff` · 次要 `#868e96` · 箭头 `#7048e8`（紫）

| 语义 | 色值 | 用在哪 |
| --- | --- | --- |
| 重点 | `#ffec99` | 黄=荧光笔，一页一个 |
| 流程 | `#b2f2bb` | 绿=做过的步骤 |
| 输入 | `#a5d8ff` | 蓝=进来的东西 |
| 提醒 | `#ffc9c9` | 红=坑、警告、反例 |
| 结构 | `#d0bfff` | 紫=分类容器，别和箭头同色混用 |
| 正文 | `#ffffff` | 白卡 + 排线≈无填充，只剩手绘描边 |

规则：这套的涂抹感来自 `fillStyle: hachure`——白卡看起来是空的，彩卡看起来是涂上去的。
所以「留白」不是偷懒，是这套风格的正色。
`流程 / 输入 / 结构` 是可选分区色，一页最多用一档，别和 `groups` 外框同名。

## 对比度底线

墨色文字压在色块上必须读得动。上面两表的色值都是**浅底**，配 `#1e1e1e` / `#151515` 文字
对比度都在 7:1 以上。自己加色时按这个底线挑，别用中饱和度的色当底。
